# 手机桥接

给安卓客户端开的局域网接口：手机配对一次后，可以看到这台电脑上 DSH 的会话列表、实时运行状态与对话内容，并向会话发送消息、停止回合、处理审批。

## 功能

- **配对**：启动时随机生成 6 位配对码（10 分钟有效，最多 12 次尝试）。在电脑上打开 `http://127.0.0.1:4318/pair` 可以看到当前服务地址和配对码；配对成功后手机保存一枚设备令牌。
- **会话列表**：`GET /api/sessions` 返回所有可见会话的标题、运行状态、待处理输入、工作目录与最近活动时间。
- **实时流**：`GET /api/sessions/<id>/stream` 使用 SSE 推送会话状态、历史快照和后续事件，只保留 `user/message`、`assistant/message`、`tool/call`、`tool/result`、`turn/end` 等对话相关事件，并截断过长文本。
- **交互**：`POST /api/sessions/<id>/prompt` 发送消息，`POST /api/sessions/<id>/cancel` 停止当前回合。
- **审批接管**：手机端在最近 60 秒内访问过桥接时，插件会作为最后一道审批应答者，把审批请求转发给手机；90 秒内没有回答则交回桌面端。手机未连接时完全不介入，桌面端体验不变。
- **健康检查**：`GET /api/health` 返回主机名、会话数、运行中数量。

## 使用

1. 在插件管理器里启用本插件后，桥接监听 `0.0.0.0:4318`。
2. 在电脑浏览器打开 `http://127.0.0.1:4318/pair` 获取服务地址与配对码。
3. 手机与电脑处于同一局域网，在 App 的 Harness 模式里填写地址与配对码。
4. 首次连接若弹出 Windows 防火墙提示，请允许专用网络访问。

## 已知限制

- 仅面向同一局域网的明文 HTTP；不要在公网直接暴露 4318 端口。令牌与配对码是唯一的访问控制手段。
- 只覆盖普通会话：子代理会话、终端、文件读写、计划与工作流面板不在本接口范围内。
- 审批转发只在手机最近活跃时接管，超时后交回桌面端；提问（`ask_user_question`）仍需在电脑上回答。
- 事件压缩与过滤逻辑在插件代码修改后需要重新加载插件或重启 DSH 才会生效。
- 协议版本为 1，与本仓库的安卓客户端耦合；改动需要同步两侧。
